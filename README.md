# אמא ואני – MVP חנות אונליין (Next.js)

חנות לאימהות ולתינוקות בכיוון Scandinavian Premium, בעברית ו-RTL מלא, נבנתה לפי מסמך האפיון v1.0.
"אמא ואני" הוא שם זמני.

## הרצה

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

נדרש Node 20 ומעלה. הפריסה המומלצת היא ל-Vercel (ללא הגדרות נוספות).

## מבנה

```
src/
  app/
    tokens.css          ← כל ה-Design Tokens: צבעים, טיפוגרפיה, ריווח, רדיוסים, אנימציות
    globals.css         ← עיצוב הרכיבים (Mobile First, תכונות לוגיות ל-RTL)
    page.tsx            ← עמוד הבית (10 האזורים מהאפיון)
    products/ category/[slug]/ product/[slug]/ search/ deals/ creator-picks/
    cart/ checkout/ checkout/success/ guides/ about/ contact/ faq/ policies/[slug]/ account/
  components/           ← ספריית הרכיבים (ProductCard, CartDrawer, AffiliateCTA, Accordion...)
  context/CartContext   ← סל קניות (localStorage), קופונים, משלוח חינם
  lib/brand.ts          ← שם המותג, טלפון, מייל, סף משלוח חינם – החלפת מותג מתבצעת כאן
  lib/data.ts           ← מוצרי דמו, קטגוריות, מדריכים, קופונים, שיטות משלוח
```

## עקרונות שמומשו

- **הפרדה בין רכישה ישירה ל-Affiliate.** מוצר Affiliate לא יכול להיכנס לסל, וזה נאכף גם בקוד (`CartContext.add`). כל כרטיס מוצר ועמוד מוצר מציגים את אופן הרכישה. קישורי שותף נפתחים בחלון חדש עם `rel="sponsored"`.
- **אמינות.** אין ביקורות מומצאות, טיימרים או מלאי מזויף. מחיר קודם מוצג רק כשיש `compareAt`. אזור Social Proof מוסתר עד שיהיה תוכן אמיתי.
- **תמונות.** כל עוד אין תמונות עם זכויות שימוש, מוצג placeholder מעוצב. כדי להחליף, מוסיפים `images: ["/products/x-1.jpg", ...]` למוצר, ו-next/image מטפל ב-WebP/AVIF וב-lazy loading.
- **נגישות.** ניגודיות AA, ניווט מלא במקלדת, Focus trap ו-Esc בחלוניות, הודעות שגיאה ליד כל שדה, תמיכה ב-`prefers-reduced-motion`, ו-Skip link.
- **אנימציות.** שולטים בהן משכי הזמן שמוגדרים ב-tokens. אין Scroll hijacking, אין Parallax ואין קרוסלה אוטומטית.

## עיצוב (גרסה 2 – "בוקר ראשון בבית")
- **טיפוגרפיה:** Bellefair לכותרות (סריף עברי עדין, תחושת לוקבוק מודפס) + Assistant לטקסט ולממשק – החלופה שהאפיון הציע ל-Heebo.
- **פלטה:** הפלטה מהאפיון, עם Sage עמוק (`--moss`) לכפתורים ולפס העליון, ו-Dusty Rose רק בהערות האישיות של האמא.
- **אלמנט מזהה:** רשימת הקטגוריות הטיפוגרפית בעמוד הבית (בדסקטופ התמונה מתחלפת לפי השורה), וה-wordmark הענק בפוטר.
- **תנועה:** רגע אחד בלבד בטעינת ה-Hero. שאר האנימציות הן תגובה לפעולה (Hover, פתיחת סל, אקורדיון).

## תמונות
התמונות ב-`public/images` הן מ-Unsplash (רישיון Unsplash – שימוש מסחרי חופשי, ללא חובת קרדיט).
הן **תמונות אווירה זמניות**: תמונות המוצרים אינן מציגות את המוצרים עצמם, ולפני השקה יש להחליף אותן בצילומי המוצרים האמיתיים (מהספק, באישור, או צילום עצמי).
תמונת "בחירות האמא" היא תמונת סטוק – יש להחליף בתמונה של המשפיענית.

## קופוני דמו
`WELCOME10` נותן 10% הנחה, ו-`MOM20` נותן ₪20 הנחה.

## גרסה 3 – שיפורים מתוך השוק הישראלי
1. רשימת לידה: הוספה מכל עמוד מוצר ושיתוף בקישור אחד בוואטסאפ (`/registry`).
2. מועדפים (לב) בכל כרטיס ובעמוד מוצר, עמוד `/wishlist` ואייקון ב-Header.
3. שליחה כמתנה ב-Checkout: שם וטלפון של המקבלת, ברכה אישית, אריזת מתנה, ובלי מחירים בחבילה.
4. תשלומים: עד 3 תשלומים ללא ריבית, כולל הצגה בעמוד המוצר ובחירה ב-Checkout.
5. אמצעי תשלום ישראליים: bit, Apple Pay ו-Google Pay, עם תצוגה בסל ובפוטר.
6. משלוח אקספרס כשיטה שלישית (לא נכלל במשלוח חינם).
7. תאריכי הגעה משוערים לפי ימי עסקים בישראל (בלי שישי ושבת), עם חיתוך בשעה 13:00.
8. כפתור וואטסאפ צף, ו"שאלה על המוצר" שנשלחת עם שם המוצר.
9. תפריט נגישות: גודל טקסט, ניגודיות, הדגשת קישורים, גופן קריא ועצירת אנימציות.
10. באנר עוגיות עם אפשרות "רק הכרחיות".
11. עמוד ביטול עסקה (`/cancel`), כמקובל באתרים ישראליים.
12. מדיניות ביטולים לפי חוק הגנת הצרכן: 14 יום, 5% או 100 ₪, 4 חודשים לזכאים.
13. פרטי העסק בפוטר (שם, ח.פ. וכתובת). חובה במכירה מרחוק, ממולאים ב-`brand.ts`.
14. יצרן וארץ ייצור בכל מוצר.
15. מעקב הזמנה (`/track`).
16. כרטיס מתנה דיגיטלי (`/gift-card`).
17. "עדכנו אותי כשיחזור" במוצר שאזל.
18. טבלת מידות לשקי שינה ולהלבשה.
19. "צפית לאחרונה" בעמוד המוצר.
20. השלמה למשלוח חינם: הצעות מוצרים בסל, לפי הסכום שחסר.
21. קנייה לפי גיל בעמוד הבית (`/products?age=`).
22. אזור מתנות ורשימת לידה בעמוד הבית.
23. "שליחה לחברה": שיתוף מוצר (Web Share או וואטסאפ).
24. חיפושים אחרונים בחלון החיפוש.
25. SEO: נתונים מובנים (JSON-LD) למוצרים, Open Graph, `sitemap.xml` ו-`robots.txt`.
26. פס הודעה עליון עם שלוש ההבטחות: משלוח חינם, תשלומים וביטול.
27. עמוד אישור הזמנה עם צפי הגעה וקישור למעקב.
28. שאלות נפוצות חדשות: תשלומים, bit, שליחת מתנה ורשימת לידה.
29. תיקון RTL: טווחי מספרים (0-6, 3-5) מוצגים בסדר הנכון.

כל מה שמסומן TODO או [דמו] (סליקה, מעקב משלוח, מיילים) מחכה לחיבור Backend.

## גרסה 5: נגישות ופריסות מתקדמות
**נגישות (WCAG 2.1 AA):** בדיקת axe-core אוטומטית על 12 עמודים עברה עם 0 הפרות.
- טבעת פוקוס כפולה (רקע ומותג) על כל אלמנט אינטראקטיבי.
- כל יעדי המגע בגודל 44px לפחות.
- כפתור לעצירת הטקסט הנע (WCAG 2.2.2), ובחירה נשמרת.
- בחירת מידה וצבע עם רדיו מקורי: עובד עם החיצים במקלדת.
- חלוניות סגורות מוגדרות `inert`, ולכן הפוקוס לא נכנס אליהן.
- הכרזה לקוראי מסך על כל הוספה לסל.
- תיאור בעברית לתגיות באנגלית (NEW, SOLD OUT, הנחה).
- תיקון ניגודיות ותיקון bidi בשמות לועזיים (`<bdi>`).

**פריסות:**
- Bento שירותים: 4 עמודות בדסקטופ, 2 בטאבלט, 1 במובייל.
- Mesh gradient עם טקסטורת רעש ב"כל שלב והדברים שלו" ובכרטיס המתנה.
- מצב כהה לא נוסף בכוונה: שפת המותג בנויה על רקע שמנת.
